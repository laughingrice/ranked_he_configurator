This browser can't talk to USB keyboards. Open this page in Chrome, Edge, Brave or another Chromium browser on desktop (WebHID). You can still look around with Demo.
Plug the keyboard in by cable, click Connect keyboard and choose Master 65% US Keyboard. Settings are written straight to the keyboard and stay there. The keyboard can't report its settings back, so this page remembers what it wrote (in this browser). Use Profiles → Settings file to share it with the ranked.py tool.

Lighting effect

Built-in effects. Per-key colours are on the next tab.
With rapid trigger on, the first press happens at actuation + press sensitivity (firmware behaviour). Readings top out near 4.0 mm, so keep actuation ≤ 3.6 mm. 0.1 mm RT is at sensor-noise level.

Layer

On a Mac, Win = Cmd and Alt = Option. If you swapped them in macOS, combos get swapped too (use opt+c for Cmd+C). Fn1 + Win toggles Win-lock. Fn and Fn2 can't be remapped on the base layer.

Macros

Bind a macro on the Keymap tab: macro:NAME (once), macro:NAME*3, macro:NAME@hold (repeat while held), macro:NAME@toggle (until any key).
